# 🎮 Yugioh Tool

> ✨ A simple and convenient tool for your Yugioh game.

Yugioh Tool helps players access useful customization features through a clean, easy-to-use interface.

> 💬 Want more information or support?  
> 🎧 [Join our Discord community](https://discord.gg/4q86kxcM9w)

## 🌟 What Can This Tool Do?

This application gives you more control over your game progress and starting experience.

| # | Feature | Description |
|---:|---|---|
| 1 | ⭐ **Change Stars** | Adjust your Stars amount |
| 2 | 💠 **Change Souls** | Modify your available Souls |
| 3 | 🎟️ **Change Golden Tickets** | Modify your available Golden Tickets |
| 4 | 🎫 **Change Tournament Tickets** | Modify your available Tournament Tickest |
| 5 | 🎟️ **Change Standard Tickets** | Modify your available Standard Tickest |
| 6 | 👤 **Change Player Name** | Customize your in-game player name |
| 7 | 🃏 **Choose a Starting Card** | Start with any card available in the game system |
| 8 | 🔓 **Unlock All NPCs** | Unlock all currently available NPCs |
| 9 | ⚡ **Change Game Speed** | Adjust game speed up to **10x** |

Using the application is simple:

1. ⬇️ Open the **Yugioh Tool** and one click the latest update.
2. ✅ Confirm that you want to apply the update.
3. 🎮 Launch the game and enjoy.
4. 📝 Click the **NOTE** button inside the application to view a quick summary of all available functions.
